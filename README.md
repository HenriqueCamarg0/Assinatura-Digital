# Gerador de Assinatura Digital

![Logo JaVagas](img/logoJavagas2.png)

## 📝 Descrição

O Gerador de Assinatura Digital é uma aplicação web que permite aos colaboradores da JaVagas criar assinaturas de e-mail personalizadas e profissionais de forma rápida e fácil. O usuário precisa apenas preencher seus dados pessoais e a assinatura é automaticamente gerada, podendo ser baixada como imagem.

## ✨ Características

- 🎨 Interface moderna e responsiva
- 📱 Compatível com dispositivos móveis e desktop
- 📝 Preenchimento em tempo real da assinatura
- ✅ Validação de formulários com feedback visual
- 📥 Download da assinatura como imagem PNG
- 🔄 Prévia instantânea da assinatura

## 🚀 Como Usar

### Online

Acesse a aplicação em: *[Adicione o link para a aplicação hospedada aqui, se disponível]*

### Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/assinatura-digital.git
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd assinatura-digital
   ```

3. Abra o arquivo `index.html` em seu navegador.

4. Preencha seus dados no formulário e clique em "Gerar Assinatura".

5. Após gerar a assinatura, clique em "Baixar Assinatura" para salvá-la como imagem.
